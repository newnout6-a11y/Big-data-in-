# Разбор файла ingest.py

## Что делает этот файл

Читает все 575 PDF из папки `all_pdfs`, извлекает текст, разбивает его на небольшие куски (чанки), определяет кейс каждого куска и сохраняет всё в файл `chunks.jsonl`. Этот файл потом использует `embed_and_load.py`.

---

**Строка 2:** Аналогично — путь к выходному файлу `chunks.jsonl`.

**Зачем так сложно:** Если запустить скрипт из другой папки, пути `"all_pdfs"` и `"chunks.jsonl"` будут неправильными. Этот способ всегда находит файлы рядом со скриптом.

```python
размер_чанка = 800
перекрытие = 100
```

**`размер_чанка = 800`** — максимальный размер одного куска текста в символах. ~800 символов это примерно 1 абзац. Слишком маленький чанк — теряем контекст. Слишком большой — хуже работает семантический поиск.

**`перекрытие = 100`** — последние 100 символов предыдущего чанка повторяются в начале следующего. Это нужно чтобы фрагменты, попавшие на границу двух кусков, не терялись.

### Функция `извлечь_текст_из_пдф`

```python
def извлечь_текст_из_пдф(путь):
    страницы = []
    try:
        читалка = pypdf.PdfReader(путь)
        for номер, страница in enumerate(читалка.pages, start=1):
            текст = страница.extract_text()
            if текст and len(текст.strip()) > 50:
                страницы.append((номер, текст.strip()))
    except Exception:
        pass
    return страницы
```

**`страницы = []`** — начинаем с пустым списком.

**`try: ... except Exception: pass`** — если PDF повреждён или защищён паролем — просто пропускаем, не падаем.

**`pypdf.PdfReader(путь)`** — открываем PDF.

**`enumerate(читалка.pages, start=1)`** — перебираем страницы, нумерация с 1 (как в реальном документе).

**`страница.extract_text()`** — извлекаем текст со страницы.

**`if текст and len(текст.strip()) > 50`** — пропускаем страницы, где текста меньше 50 символов (обложки, пустые страницы, только рисунки).

**`страницы.append((номер, текст.strip()))`** — добавляем пару: номер страницы и её текст.

### Функция `разбить_на_чанки`

```python
def разбить_на_чанки(текст, размер, перекр):
    чанки = []
    начало = 0
    while начало < len(текст):
        конец = начало + размер
        кусок = текст[начало:конец].strip()
        if len(кусок) > 80:
            чанки.append(кусок)
        начало = конец - перекр
    return чанки
```

**`начало = 0`** — начинаем с первого символа текста.

**`while начало < len(текст)`** — идём по тексту, пока не дойдём до конца.

**`конец = начало + размер`** — вычисляем конец текущего куска.

**`текст[начало:конец]`** — вырезаем кусок из строки.

**`if len(кусок) > 80`** — не сохраняем совсем маленькие обрезки (например последний фрагмент в 10 символов).

**`начало = конец - перекр`** — следующий кусок начинается не с `конец`, а чуть раньше — с перекрытием. Так мы не теряем информацию на стыках.


**`запись`** — словарь с 4 полями. Именно эти поля потом попадут в Qdrant как payload (метаданные).

**`json.dumps(..., ensure_ascii=False)`** — преобразует словарь в строку JSON. `ensure_ascii=False` нужно чтобы русские символы не превратились в `\u0442\u0435\u043a\u0441\u0442`.

**`+ "\n"`** — каждая запись на отдельной строке. Формат `.jsonl` (JSON Lines) — каждая строка это отдельный JSON-объект.

## Что получается на выходе

Файл `chunks.jsonl` — каждая строка выглядит так:

```json
{"text": "Bayesian optimization was used to improve reaction yield...", "document": "s13321-021-00577-1.pdf", "page": 5, "case": "выход_реакции"}
```

## Как запустить

```
python ingest.py
```

Работает 3–10 минут в зависимости от скорости диска. Выводит прогресс каждые 50 файлов.
