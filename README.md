# Навигатор цифровой химии

Система семантического поиска по 575 научным документам о Big Data в химии.

## Структура файлов

```
cases.py              — 15 кейсов + авто-тегирование
ingest.py             — PDF → чанки → chunks.jsonl
embed_and_load.py     — чанки → Qdrant (с нуля)
embed_resume.py       — продолжить прерванное векторизирование
app.py                — Streamlit-интерфейс
fallback_answers.py   — заготовленные ответы (демо-режим)
запуск.py             — авто-запуск Streamlit + SSH-туннель + QR-код
.env                  — ключ Groq API
all_pdfs/             — 575 PDF документов
qdrant_db/            — база данных (создаётся автоматически)
qr.png                — QR-код для публичной ссылки (создаётся автоматически)
```

## Первый запуск (один раз)

**Шаг 1.** Заполни `.env`:
```
GROQ_API_KEY=твой_ключ_с_console.groq.com
```

**Шаг 2.** Извлечь текст из PDF:
```
python ingest.py
```
Занимает 5–10 минут. Создаёт файл `chunks.jsonl`.

**Шаг 3.** Создать векторную базу:
```
python embed_and_load.py
```
Занимает 30–60 минут (CPU). Создаёт папку `qdrant_db/` с 46 026 векторами.

Если процесс прервался (закрылся терминал, слетела сессия) — продолжить можно так:
```
python embed_resume.py
```
Скрипт сам поймёт сколько точек уже в базе и дозапустит оставшееся.

**Шаг 4.** Запустить приложение:
```
streamlit run app.py
```
Открыть в браузере: `http://localhost:8501`

## Последующие запуски

Шаги 2 и 3 делать только один раз. После этого — одна команда:
```
streamlit run app.py
```

## Запуск с публичным доступом (для защиты)

Для демонстрации из аудитории — одна команда сразу поднимает сайт, создаёт публичную ссылку (сервис localhost.run) и генерирует QR-код:

```
python запуск.py
```

Что происходит:

1. Убиваются старые процессы Streamlit/ssh/cloudflared
2. Запускается `streamlit run app.py` на порту 8501
3. Скрипт ждёт пока Streamlit станет доступен
4. Через встроенный SSH поднимается туннель к `localhost.run`
5. Из лога выдёргивается URL вида `https://xxx.lhr.life`
6. Генерируется `qr.png` и открывается в просмотрщике

Ссылка работает из РФ без VPN. Нажать `Ctrl+C` — всё корректно останавливается.

## Если нет интернета на защите

В интерфейсе включить тумблер **«Демо-режим»** — покажет 5 заготовленных ответов без обращения к API.

## Получить Groq API ключ

1. Зайти на `console.groq.com`
2. Зарегистрироваться
3. API Keys → Create API Key
4. Скопировать ключ в `.env`
