# Навигатор цифровой химии

RAG-система семантического поиска по ~577 научным документам (PDF и DOCX) о применении Big Data в химии. Задаёшь вопрос на русском — получаешь ответ на основе найденных фрагментов с указанием источников и страниц.

## Из чего собрано

| Слой | Технология |
|---|---|
| Интерфейс | Streamlit (wide layout, кастомные CSS, три вкладки) |
| Эмбеддинги | `intfloat/multilingual-e5-base` — 768-мерные векторы |
| Векторная БД | Qdrant в embedded-режиме, косинусная метрика |
| LLM | Groq API, `llama-3.3-70b-versatile` (с автооткатом на `llama-3.1-8b-instant`) |
| Публичный доступ | SSH-туннель через `localhost.run` (работает из РФ без VPN) |

## Структура файлов

| Файл | Назначение |
|---|---|
| `app.py` | Только логика: обработчики, Qdrant, Groq, вкладки. 393 строки |
| `дизайн.py` | Весь визуал: CSS-блок + HTML-рендереры секций. 564 строки |
| `cases.py` | 15 тематических кейсов + авто-тегирование по ключевым словам |
| `fallback_answers.py` | Заготовленные ответы для демо-режима (без обращения к API) |
| `ingest.py` | PDF и DOCX → чанки по ~800 символов с overlap 100 → `chunks.jsonl` |
| `embed_resume.py` | Инкрементальная векторизация чанков в Qdrant |
| `запуск.py` | Всё-в-одном: убивает старые процессы, поднимает Streamlit, SSH-туннель, генерит QR |
| `сгенерировать_заряженный_pdf.py` + `razdely_zaryazhennogo.py` | Генерация обзорного PDF с ответами на демо-вопросы |
| `requirements.txt` | Зависимости Python |
| `.env.example` | Шаблон для ключей Groq |
| `.gitignore` | Исключает `.env`, `qdrant_db/`, `chunks.jsonl`, `all_pdfs/`, логи |
| `all_pdfs/` | Сырые документы (в git не попадают) |
| `qdrant_db/` | Векторная БД (генерируется локально) |
| `chunks.jsonl` | Все чанки с метаданными (генерируется из `all_pdfs/`) |

## Первый запуск

**1. Подготовить окружение**

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

**2. Заполнить `.env`** (скопировать `.env.example` → `.env`)

```
GROQ_API_KEY=gsk_...
GROQ_API_KEY_2=gsk_...    # опционально, резервный ключ от другого аккаунта
```

**3. Положить документы** в `all_pdfs/` (PDF и/или DOCX).

**4. Извлечь чанки**

```bash
python ingest.py
```

Занимает 1–10 минут в зависимости от числа файлов. Создаёт `chunks.jsonl`.

**5. Векторизовать в Qdrant**

```bash
python embed_resume.py
```

Скрипт смотрит сколько точек уже в БД и догружает только новые. Первый запуск на чистой БД = 10–30 минут (CPU). Если прервётся — повторный запуск продолжит с того же места.

**6. Запустить приложение**

```bash
streamlit run app.py
```

Открыть `http://localhost:8501`.

## Запуск для защиты (с публичной ссылкой)

Одна команда делает всё: убивает старые процессы на порту 8501, поднимает Streamlit, создаёт туннель на `localhost.run`, генерит `qr.png` и открывает его.

```bash
python запуск.py
```

Результат:

```
Локально:         http://localhost:8501
Публичная ссылка: https://xxx.lhr.life
QR-код:           qr.png
```

Ссылка работает с телефона без VPN. `Ctrl+C` — корректная остановка.

## Режимы работы

- **Онлайн (основной):** Qdrant ищет похожие фрагменты, Groq LLM генерирует ответ со ссылками на документы и страницы.
- **Демо-режим** (тумблер в UI): подставляет 5 заготовленных ответов из `fallback_answers.py` без интернета — страховка если API упал.

## Устойчивость к лимитам Groq

- Два API-ключа из разных организаций → автофолбэк при 429.
- Если обе организации упёрлись в суточный TPD на 70b → автооткат на 8b (отдельная квота).
- Извлечение формул и перевод всегда идут на 8b, чтобы не съедать квоту 70b.
