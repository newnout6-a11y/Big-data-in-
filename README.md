# Навигатор цифровой химии

RAG-система семантического поиска по 575 научным документам (PDF + DOCX) о применении Big Data в химии. Задаёшь вопрос на русском — получаешь ответ на основе найденных фрагментов с интерактивными цитатами и ссылками на источники.

> **Хочешь понять весь проект за 2 часа?** → Открой [`ГАЙД_ЗА_2_ЧАСА.md`](ГАЙД_ЗА_2_ЧАСА.md). Там вся теория RAG, Qdrant, Groq и разбор каждого модуля.

## Архитектура

| Слой | Технология |
|---|---|
| Интерфейс | Streamlit (wide layout, кастомные CSS, три вкладки) |
| Эмбеддинги | `intfloat/multilingual-e5-base` — 768-мерные векторы, RU+EN |
| Векторная БД | Qdrant в embedded-режиме, метрика Cosine, HNSW-индекс |
| LLM | Groq API: `llama-3.3-70b-versatile` (с автооткатом на `llama-3.1-8b-instant`) |
| Публичный доступ | SSH-туннель через `localhost.run` (работает из РФ без VPN) |

## Что под капотом

Помимо базовой RAG-схемы реализованы:

- **Двойной фильтр мусора** — отсев библиографии, колонтитулов, таблиц цифр, кодов генов до отправки в LLM.
- **Чистка PDF cmap-артефактов** — `¼` → `=`, `þ` → `+`, лигатуры fi/fl и т. д.
- **Embedding-пост-проверка маркеров** — каждый `[N]` в ответе LLM проверяется через cos-sim, неверные удаляются.
- **Перенос маркеров из формул** — `[N]` внутри `$$...$$` выносятся за пределы LaTeX-блока, чтобы KaTeX не съел HTML тултипа.
- **Интерактивные цитаты** — наведение на `[N]` показывает реальный фрагмент (до 800 символов) + документ + страницу.
- **Группировка источников** — несколько маркеров в один документ показываются одной строкой `[2, 3]`.
- **Условный показ блока «Источники»** — если LLM не использовала ни одного `[N]` (отказ), блок не показывается.
- **Автофолбэк по ключам и моделям** — 3 ключа Groq + откат с 70B на 8B при упирании в TPD.

## Первый запуск

**1. Подготовить окружение**

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

**2. Заполнить `.env`** (скопировать `.env.example` → `.env`)

```env
GROQ_API_KEY=gsk_your_primary_key
GROQ_API_KEY_2=gsk_your_fallback_key    # опционально, резервный аккаунт
GROQ_API_KEY_3=gsk_your_third_key       # опционально, ещё резерв
```

Получить ключи: [console.groq.com](https://console.groq.com/) → Sign up → API Keys → Create.

**3. Положить документы** в `all_pdfs/` (PDF и/или DOCX, любой язык).

**4. Извлечь чанки**

```bash
python ingest.py
```

Занимает 1–10 минут. Создаёт `chunks.jsonl` с ~46 000 чанков из 575 документов.

**5. Векторизовать в Qdrant**

```bash
python embed_resume.py
```

Скрипт инкрементальный: смотрит, сколько точек уже в БД, и догружает остаток. Первый запуск на чистой БД — 10–30 минут (CPU). Если упало — повторный запуск продолжит с того же места.

**6. Запустить приложение**

```bash
streamlit run app.py
```

Открыть `http://localhost:8501`.

## Запуск для защиты (с публичной ссылкой)

Одна команда делает всё:

```bash
python запуск.py
```

Что происходит:

1. Убиваются старые процессы на порту 8501 + любые висящие `python.exe app.py`.
2. Поднимается Streamlit в фоне.
3. Создаётся SSH-туннель: `ssh -R 80:localhost:8501 nokey@localhost.run` → выдаётся `https://xxx.lhr.life`.
4. Генерится `qr.png` с этим URL и автоматически открывается.
5. Процесс держится до Ctrl+C.

```text
Локально:         http://localhost:8501
Публичная ссылка: https://xxx.lhr.life
QR-код:           qr.png
```

Ссылка работает с телефона **из РФ без VPN** (в отличие от Cloudflare Tunnel).

## Режимы работы

- **Онлайн (основной)**: Qdrant ищет похожие фрагменты, фильтры выкидывают мусор, Groq LLM генерирует ответ с маркерами `[N]`, embedding-пост-проверка отбраковывает неверные ссылки.
- **Демо-режим** (тумблер в UI): подставляет 5 заготовленных ответов из `fallback_answers.py` без обращения к интернету. Страховка для защиты, если API упал.

## Устойчивость к лимитам Groq

- **Три ключа** в `.env` (разные аккаунты) → автофолбэк при 429 Rate Limit.
- **Авто-откат с 70B на 8B** при упирании в TPD основной модели — у 8B квота отдельная.
- **Перевод фрагментов и извлечение формул** идут на 8B, чтобы не съедать квоту 70B на основные ответы.

## Системные требования

- **Python 3.10+** (тестировано на 3.12).
- **Windows / macOS / Linux** — `запуск.py` написан для Windows (использует `taskkill`, PowerShell), на других ОС нужно адаптировать.
- **OpenSSH-клиент** (`ssh.exe`) — стандартно в Windows 10+.
- **~2 ГБ свободной RAM** при работе (модель + Qdrant + Streamlit).
- **~250 МБ свободного диска** (`qdrant_db/` + `chunks.jsonl` + cache модели).
- **GPU не нужен** — векторизация и поиск отлично работают на CPU.
