# Разбор файла запуск.py

## Что делает этот файл

Один скрипт делает всё для демонстрации приложения: убивает старые процессы, поднимает Streamlit на порту 8501, создаёт публичный SSH-туннель через `localhost.run`, генерит QR-код. Одна команда `python запуск.py` — и на защите можно открывать ноутбук/телефон и показывать.

**Зачем:** обычно нужно запустить 3–4 команды в разных терминалах. Здесь всё автоматизировано, плюс автоматическая очистка зависших процессов.

---

## Импорты и константы

```python
import os
import re
import sys
import time
import subprocess
import qrcode

корень = os.path.dirname(os.path.abspath(__file__))
порт = 8501
путь_лога = os.path.join(корень, "_tunnel.log")
путь_qr = os.path.join(корень, "qr.png")
```

**Библиотеки:**

- `subprocess` — запускает внешние команды (taskkill, netstat, streamlit, ssh, powershell).
- `qrcode` — генерация QR-изображения из URL.
- `re` — парсим публичный URL из лога туннеля.

**Константы:**

- `корень` — абсолютный путь к папке проекта. Работает независимо от cwd.
- `порт = 8501` — дефолтный порт Streamlit.
- `путь_лога` — куда SSH пишет свой stdout (оттуда достаём публичный URL).
- `путь_qr` — куда сохранять QR-изображение.

## Завершение старых процессов

```python
def завершить_старые():
    # Старые туннели
    for имя in ("cloudflared.exe", "ssh.exe"):
        try:
            subprocess.run(["taskkill", "/F", "/IM", имя], capture_output=True)
        except Exception:
            pass

    # Всё что слушает порт 8501 (старый Streamlit)
    try:
        netstat = subprocess.run(
            ["netstat", "-ano", "-p", "tcp"],
            capture_output=True, text=True, encoding="cp866", errors="ignore"
        )
        pids_к_убою = set()
        for строка in netstat.stdout.splitlines():
            if f":{порт}" in строка and "LISTENING" in строка.upper():
                части = строка.split()
                if части and части[-1].isdigit():
                    pids_к_убою.add(части[-1])
        for pid in pids_к_убою:
            subprocess.run(["taskkill", "/F", "/PID", pid], capture_output=True)
    except Exception:
        pass

    # Любые python-процессы, запускающие наш app.py
    try:
        subprocess.run(
            ["powershell", "-NoProfile", "-Command",
             "Get-CimInstance Win32_Process | "
             "Where-Object { $_.Name -in 'python.exe','pythonw.exe' -and "
             "$_.CommandLine -like '*app.py*' } | "
             "ForEach-Object { Stop-Process -Id $_.ProcessId -Force -ErrorAction SilentlyContinue }"],
            capture_output=True, timeout=10
        )
    except Exception:
        pass
```

**Три уровня очистки:**

### 1. По имени процесса

`taskkill /F /IM cloudflared.exe` убивает все процессы `cloudflared.exe`. То же для `ssh.exe`. `/F` — force (без запроса подтверждения), `/IM` — по имени образа.

### 2. По порту 8501 через netstat

Если Streamlit уже запущен и держит порт 8501, новый запуск упадёт с `port already in use`. Чтобы избежать — находим PID процесса, слушающего этот порт:

```
netstat -ano -p tcp
```

Пример вывода:

```
  TCP    0.0.0.0:8501           0.0.0.0:0              LISTENING       12345
```

Последний столбец — PID. Парсим, убиваем через `taskkill /F /PID 12345`.

**`encoding="cp866"`** — русская Windows-консоль использует эту кодировку для вывода.

**`set()`** — иногда netstat показывает один и тот же PID для IPv4 и IPv6 — через set дедуплицируем.

### 3. По командной строке через PowerShell

Некоторые зависшие Python-процессы могли уже отпустить порт, но ещё висят. Ловим их через WMI:

```powershell
Get-CimInstance Win32_Process | Where-Object {
    $_.Name -in 'python.exe','pythonw.exe' -and $_.CommandLine -like '*app.py*'
} | Stop-Process -Force
```

Ищет все python-процессы с `app.py` в командной строке и убивает.

**Все три обёрнуты в `try/except pass`** — если какой-то вариант не сработал, переходим к следующему. Цель — не упасть, а максимально почистить.

## Подготовка лога туннеля

```python
def подготовить_лог():
    """Освобождаем _tunnel.log. Если занят — ретрай, иначе уникальное имя."""
    global путь_лога
    for _ in range(6):
        try:
            if os.path.exists(путь_лога):
                os.remove(путь_лога)
            return
        except OSError:
            time.sleep(1)
    путь_лога = os.path.join(корень, f"_tunnel_{int(time.time())}.log")
```

**Проблема:** на Windows удалить файл, который открыт другим процессом — нельзя (получишь `PermissionError`). Если предыдущий SSH завис с открытым хэндлом — старый `_tunnel.log` не удалить.

**Решение:**

1. Пытаемся 6 раз с секундным интервалом.
2. Если не удалось — используем новое имя типа `_tunnel_1777062520.log` (unix timestamp).

`global путь_лога` — меняем переменную модуля (чтобы все остальные функции видели новое имя).

## Запуск Streamlit

```python
def запустить_streamlit():
    питон = sys.executable
    процесс = subprocess.Popen(
        [питон, "-m", "streamlit", "run", os.path.join(корень, "app.py"),
         "--server.headless", "true", "--server.port", str(порт)],
        cwd=корень,
        stdout=subprocess.DEVNULL,
        stderr=subprocess.DEVNULL,
        creationflags=subprocess.CREATE_NEW_PROCESS_GROUP if os.name == "nt" else 0
    )
    return процесс
```

**`sys.executable`** — путь к текущему интерпретатору Python. Гарантирует что streamlit запускается от того же Python, что и скрипт (важно в venv).

**`-m streamlit run ...`** — запуск модуля streamlit как скрипта.

**`--server.headless true`** — не открывать браузер автоматически (нам это не нужно, мы сами открываем QR).

**`stdout=DEVNULL, stderr=DEVNULL`** — Streamlit много логирует, нам это не интересно, тушим.

**`CREATE_NEW_PROCESS_GROUP`** (только Windows) — процесс получает свою группу. Нужно чтобы Ctrl+C в нашем скрипте не убивал дочерний Streamlit раньше времени (`terminate()` мы вызываем сами в `finally`).

## Ожидание готовности Streamlit

```python
def дождаться_streamlit(таймаут=60):
    import urllib.request
    старт = time.time()
    while time.time() - старт < таймаут:
        try:
            urllib.request.urlopen(f"http://localhost:{порт}", timeout=1)
            return True
        except Exception:
            time.sleep(1)
    return False
```

Streamlit запускается 5–20 секунд. В цикле пытаемся открыть `http://localhost:8501` — как только получилось, возвращаем `True`. Если за 60 секунд не ответил — fail.

Это «health check» — классический приём проверки что сервис поднялся.

## Создание SSH-туннеля

```python
def запустить_туннель():
    подготовить_лог()
    файл = open(путь_лога, "w", encoding="utf-8", errors="ignore")
    аргументы = [
        "ssh",
        "-o", "StrictHostKeyChecking=no",
        "-o", "UserKnownHostsFile=NUL",
        "-o", "ServerAliveInterval=30",
        "-o", "PasswordAuthentication=no",
        "-o", "BatchMode=yes",
        "-T",
        "-R", f"80:localhost:{порт}",
        "nokey@localhost.run"
    ]
    процесс = subprocess.Popen(
        аргументы,
        stdout=файл,
        stderr=subprocess.STDOUT,
        stdin=subprocess.DEVNULL,
        creationflags=subprocess.CREATE_NEW_PROCESS_GROUP if os.name == "nt" else 0
    )
    return процесс, файл
```

**Как работает `localhost.run`:**

- Сервис на `localhost.run` принимает SSH-соединения без пароля (пользователь `nokey`).
- Мы открываем SSH-сессию с **reverse port forwarding**: `-R 80:localhost:8501`.
- Это значит: «на стороне сервера открой порт 80 и перенаправляй его в мой localhost:8501».
- Сервер выдаёт публичный URL вида `https://abc123.lhr.life`, который проксирует на наш компьютер.
- Работает из РФ без VPN — сервис не блокирован.

**SSH-опции:**

| Опция | Что делает |
|---|---|
| `StrictHostKeyChecking=no` | Не спрашивать «доверять хосту?» при первом подключении |
| `UserKnownHostsFile=NUL` | Не сохранять ключ хоста в known_hosts |
| `ServerAliveInterval=30` | Пинговать сервер каждые 30 сек чтобы не упал по таймауту |
| `PasswordAuthentication=no` | Не пытаться ввести пароль (нам он не нужен) |
| `BatchMode=yes` | Не спрашивать ничего интерактивно |
| `-T` | Не выделять терминал (он нам не нужен, только туннель) |
| `-R 80:localhost:8501` | Reverse forwarding: удалённый порт → локальный |

**`stdout=файл`** — весь вывод SSH идёт в `_tunnel.log`. Там первая строка содержит публичный URL.

## Парсинг публичного URL

```python
def получить_url(таймаут=40):
    старт = time.time()
    шаблон = re.compile(r"https://[a-zA-Z0-9\-]+\.lhr\.life")
    while time.time() - старт < таймаут:
        if os.path.exists(путь_лога):
            try:
                with open(путь_лога, "r", encoding="utf-8", errors="ignore") as f:
                    содержимое = f.read()
                совпадение = шаблон.search(содержимое)
                if совпадение:
                    return совпадение.group(0)
            except Exception:
                pass
        time.sleep(1)
    return None
```

**Что в `_tunnel.log`:**

```
===============================================================================
Welcome to localhost.run!
...
** your connection id is xxx, please mention it if you send me a message about an issue **

abc123def.lhr.life tunneled with tls termination, https://abc123def.lhr.life
```

Регулярка `https://[a-zA-Z0-9\-]+\.lhr\.life` ловит нужный URL. Проверяем каждую секунду до 40 секунд — сервер может отвечать не сразу.

## QR-код

```python
def сгенерировать_qr(url):
    картинка = qrcode.make(url)
    картинка.save(путь_qr)
    return путь_qr

def открыть_файл(путь):
    if os.name == "nt":
        os.startfile(путь)
    else:
        subprocess.run(["xdg-open", путь])
```

`qrcode.make(url)` — PIL-картинка с QR. `os.startfile` на Windows открывает файл в дефолтном приложении (Фото). На Linux — `xdg-open`.

## Главный поток

```python
print("=" * 60)
print("  НАВИГАТОР ЦИФРОВОЙ ХИМИИ · запуск")
print("=" * 60)

print("\n[1/4] останавливаем старые процессы...")
завершить_старые()
time.sleep(2)

print("[2/4] запускаем Streamlit на порту", порт, "...")
streamlit_процесс = запустить_streamlit()
if not дождаться_streamlit():
    print("\nОШИБКА: Streamlit не запустился за 60 секунд")
    sys.exit(1)
print("      Streamlit готов:  http://localhost:" + str(порт))

print("[3/4] создаём туннель через localhost.run (SSH)...")
туннель_процесс, лог_файл = запустить_туннель()
публичный_url = получить_url()
if not публичный_url:
    print("\nОШИБКА: не удалось получить публичный URL за 40 секунд")
    print("Проверь лог:", путь_лога)
    туннель_процесс.terminate()
    streamlit_процесс.terminate()
    sys.exit(1)

print("[4/4] генерируем QR-код...")
сгенерировать_qr(публичный_url)
открыть_файл(путь_qr)

print("\n" + "=" * 60)
print("  ГОТОВО")
print("=" * 60)
print(f"\n  Локально:         http://localhost:{порт}")
print(f"  Публичная ссылка: {публичный_url}")
print(f"  QR-код:           {путь_qr}")
print("\n  Наведи камеру телефона на QR или открой ссылку")
print("  Работает из РФ без VPN")
print("  Нажми Ctrl+C чтобы остановить")
print()

try:
    while True:
        time.sleep(1)
except KeyboardInterrupt:
    print("\n\nОстанавливаем...")
    туннель_процесс.terminate()
    streamlit_процесс.terminate()
    try:
        лог_файл.close()
    except Exception:
        pass
    print("Всё остановлено.")
```

**Последовательность:**

1. **Баннер** — видно что это наш скрипт.
2. **Очистка старых процессов** — даём им 2 секунды чтобы освободить ресурсы.
3. **Запуск Streamlit** + health check.
4. **Открытие SSH-туннеля** + парсинг URL из лога.
5. **Генерация QR** и автооткрытие в просмотрщике.
6. **Финальный вывод** с тремя ссылками.
7. **Бесконечный цикл `while True`** — скрипт не завершается, чтобы дочерние процессы жили.
8. **`KeyboardInterrupt` (Ctrl+C)** — корректно глушим Streamlit и туннель, закрываем лог.

## Что будет если...

| Ситуация | Поведение |
|---|---|
| SSH не установлен в системе | Ошибка на шаге 3, скрипт закроется |
| Порт 8501 держит другая программа (не python) | `завершить_старые` её всё равно убьёт |
| Нет интернета | Туннель не поднимется за 40 секунд → ошибка, но локально Streamlit работает |
| Нажал Ctrl+C | Оба процесса гасятся, лог закрывается, выход без мусора |
| `localhost.run` перегружен | URL не появится в логе → таймаут 40с → ошибка |

## Что запомнить на защиту

1. **Три уровня очистки процессов:** по имени (taskkill /IM), по порту (netstat), по командной строке (PowerShell WMI).
2. **Health check через `urllib.urlopen`** — ждём пока Streamlit реально ответит, а не просто «процесс запущен».
3. **SSH reverse port forwarding** (`-R 80:localhost:8501`) — ключевая техника для публичного доступа без регистрации и без VPN.
4. **`localhost.run`** — бесплатный сервис, не блокирован в РФ, не требует аккаунта.
5. **`try/finally` с `terminate()`** — гарантирует что дочерние процессы убьются при любом выходе, включая Ctrl+C.
