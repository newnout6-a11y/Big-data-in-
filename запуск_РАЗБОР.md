# Разбор файла запуск.py

## Что делает этот файл

Один скрипт делает всё, что нужно для демонстрации на защите:

1. Останавливает старые процессы (Streamlit, SSH, cloudflared)
2. Запускает `streamlit run app.py` на порту 8501
3. Ждёт пока Streamlit станет доступен (http-проверка)
4. Через SSH поднимает туннель к сервису `localhost.run` — получает публичный URL
5. Генерирует QR-код и открывает его в системном просмотрщике
6. Держит всё живым до `Ctrl+C`

После запуска у тебя есть:

- **Локальный адрес** `http://localhost:8501` — для твоего ноутбука
- **Публичная ссылка** `https://xxx.lhr.life` — работает из РФ без VPN
- **QR-код** `qr.png` — показать преподавателю / вывести на проектор

---

## Почему нужен именно SSH-туннель

Прямой доступ извне на `localhost:8501` не работает:

- Компьютер находится за NAT (роутер)
- Файрвол провайдера блокирует входящие соединения
- Публичный IP может быть динамическим

Решение — **обратный туннель**: наш ноутбук сам инициирует соединение с публичным сервером, и сервер пересылает запросы снаружи на наш порт 8501.

`localhost.run` даёт такие туннели **бесплатно, без регистрации**, через обычный SSH. Клиент SSH уже встроен в Windows 10/11 — никакие зависимости устанавливать не надо.

Преимущество перед Cloudflare Tunnel (`trycloudflare.com`): домен `lhr.life` **не заблокирован в РФ**, а `trycloudflare.com` — частично блокируется РКН.

## Построчный разбор

### Переменные

```python
корень = os.path.dirname(os.path.abspath(__file__))
порт = 8501
путь_лога = os.path.join(корень, "_tunnel.log")
путь_qr = os.path.join(корень, "qr.png")
```

`корень` — папка, где лежит сам скрипт. Нужна чтобы находить `app.py`, сохранять лог и QR рядом, а не в текущей директории терминала.

### Остановка старых процессов

```python
def завершить_старые():
    subprocess.run(["taskkill", "/F", "/IM", "cloudflared.exe"], capture_output=True)
    subprocess.run(["taskkill", "/F", "/IM", "ssh.exe"], capture_output=True)
```

Windows-команда `taskkill /F /IM имя.exe` — убивает все процессы с таким именем. Если процессов нет — не ошибка. `capture_output=True` глушит вывод.

Зачем: если предыдущий запуск не был завершён корректно (закрыли окно, зависло), старые процессы могут держать порт 8501 или SSH-соединение. Перед новым запуском чистим.

### Запуск Streamlit

```python
def запустить_streamlit():
    процесс = subprocess.Popen(
        [питон, "-m", "streamlit", "run", os.path.join(корень, "app.py"),
         "--server.headless", "true", "--server.port", str(порт)],
        cwd=корень,
        stdout=subprocess.DEVNULL,
        stderr=subprocess.DEVNULL,
    )
    return процесс
```

- **`subprocess.Popen`** — запускает команду **в фоне**, не дожидаясь завершения (в отличие от `subprocess.run`). Возвращает объект процесса, который можно будет потом убить.
- **`--server.headless true`** — запретить Streamlit автоматически открывать браузер (нам не нужно, у нас свой QR-код).
- **`stdout=subprocess.DEVNULL`** — подавить вывод Streamlit (не засорять наш собственный вывод логами).

### Ожидание готовности

```python
def дождаться_streamlit(таймаут=60):
    старт = time.time()
    while time.time() - старт < таймаут:
        try:
            urllib.request.urlopen(f"http://localhost:{порт}", timeout=1)
            return True
        except Exception:
            time.sleep(1)
    return False
```

Streamlit запускается 5–15 секунд (загружает модель, подключается к Qdrant). Мы **пингуем** `localhost:8501` каждую секунду и ждём пока он ответит. До 60 секунд терпим.

Без этого SSH-туннель начал бы работать раньше чем Streamlit готов — и первые посетители увидели бы «Connection refused».

### SSH-туннель

```python
def запустить_туннель():
    файл = open(путь_лога, "w", encoding="utf-8", errors="ignore")
    аргументы = [
        "ssh",
        "-o", "StrictHostKeyChecking=no",
        "-o", "UserKnownHostsFile=NUL",
        "-o", "ServerAliveInterval=30",
        "-o", "PasswordAuthentication=no",
        "-o", "BatchMode=yes",
        "-T",
        "-R", f"80:localhost:{порт}",
        "nokey@localhost.run"
    ]
    процесс = subprocess.Popen(аргументы, stdout=файл, stderr=subprocess.STDOUT, ...)
```

**Флаги SSH:**

- **`-R 80:localhost:8501`** — главная магия. Обратный туннель: "на удалённом сервере слушай порт 80, и весь трафик переадресуй на мой localhost:8501".
- **`-o StrictHostKeyChecking=no`** — не спрашивать "добавить хост в known_hosts?" (это интерактивно, а у нас скрипт).
- **`-o UserKnownHostsFile=NUL`** — не сохранять ключ сервера (на Windows `NUL` = `/dev/null`).
- **`-o ServerAliveInterval=30`** — слать keepalive каждые 30 сек, чтобы туннель не разорвался по таймауту.
- **`-o PasswordAuthentication=no`** + **`BatchMode=yes`** — если сервер попросит пароль — сразу падать, не висеть в ожидании.
- **`-T`** — отключить выделение псевдотерминала (нам нужен только туннель, а не shell).
- **`nokey@localhost.run`** — имя пользователя `nokey` — специальное значение сервиса `localhost.run`, которое разрешает анонимное подключение без SSH-ключа.

Весь вывод SSH перенаправляется в файл `_tunnel.log` — оттуда мы потом будем читать URL.

### Парсинг URL из лога

```python
def получить_url(таймаут=40):
    шаблон = re.compile(r"https://[a-zA-Z0-9\-]+\.lhr\.life")
    while time.time() - старт < таймаут:
        if os.path.exists(путь_лога):
            with open(путь_лога, "r", encoding="utf-8", errors="ignore") as f:
                содержимое = f.read()
            совпадение = шаблон.search(содержимое)
            if совпадение:
                return совпадение.group(0)
        time.sleep(1)
    return None
```

Через несколько секунд после запуска SSH, `localhost.run` присылает баннер с URL вида:

```text
** your connection id is ... **
33a053aff9b7b6.lhr.life tunneled with tls termination, https://33a053aff9b7b6.lhr.life
```

Мы читаем файл лога каждую секунду и ищем регулярным выражением первое совпадение `https://...lhr.life`. Как только нашли — возвращаем.

### Генерация QR

```python
def сгенерировать_qr(url):
    картинка = qrcode.make(url)
    картинка.save(путь_qr)
    return путь_qr
```

Библиотека `qrcode[pil]` — простейший способ: `make(текст)` возвращает PIL-картинку, `.save(путь)` сохраняет в PNG.

### Открытие в просмотрщике

```python
def открыть_файл(путь):
    if os.name == "nt":
        os.startfile(путь)
```

`os.startfile` на Windows — эквивалент двойного клика по файлу. Откроет PNG в дефолтном просмотрщике изображений (Photos или что установлено).

### Бесконечный цикл до Ctrl+C

```python
try:
    while True:
        time.sleep(1)
except KeyboardInterrupt:
    туннель_процесс.terminate()
    streamlit_процесс.terminate()
```

Сам скрипт ничего не делает, просто держит оба процесса живыми (Streamlit и SSH). Когда пользователь жмёт `Ctrl+C` — Python бросает `KeyboardInterrupt`, мы ловим и корректно убиваем оба процесса.

Без этого при закрытии терминала дочерние процессы могли бы остаться висеть в фоне.

## Схема работы

```text
┌─────────────────────────┐
│ запуск.py (процесс 1)   │
└────┬───────────────┬────┘
     │               │
     │ spawn         │ spawn
     ▼               ▼
┌─────────┐     ┌──────────────┐
│Streamlit│     │ ssh → lhr    │─────► Интернет (lhr.life)
│ :8501   │◄────┤ туннель      │       │
└─────────┘     └──────────────┘       ▼
                                  посетитель
                                  с QR-кода
```

## Как запустить

```
python запуск.py
```

## Как остановить

Нажать `Ctrl+C` в окне терминала. Скрипт корректно остановит Streamlit и SSH-туннель.
