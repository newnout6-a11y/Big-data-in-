# Разбор файла дизайн.py

## Что делает этот файл

Полностью отвечает за внешний вид приложения: цвета, шрифты, анимации, HTML-разметку всех секций. `app.py` только вызывает функции отсюда, сам ни одной строки CSS/HTML не содержит.

**Размер:** 564 строки. Из них 230 строк — CSS внутри строковой константы, остальное — данные визуала и функции-рендереры.

**Зачем вынесено:** разделение ответственности. Логика RAG (поиск, LLM, обработка) отдельно, визуал — отдельно. Поправить цвет кнопки можно не трогая бизнес-логику и наоборот.

```python
import re
```

## Блок CSS-стилей

```python
CSS_БЛОК = """
<style>
@import url('https://fonts.googleapis.com/css2?family=Geist...&display=swap');

:root {
    --bg: #0a0a0a;
    --bg-soft: #111111;
    --bg-card: #141414;
    --border: #1f1f1f;
    --border-strong: #2a2a2a;
    --text: #fafafa;
    --text-muted: #a3a3a3;
    --text-dim: #525252;
}
...
</style>
"""
```

**`CSS_БЛОК` — многострочная строка Python** (тройные кавычки). Внутри — готовый HTML-тег `<style>` с 220+ правилами. Это выполняется как есть при вызове `st.markdown(CSS_БЛОК, unsafe_allow_html=True)`.

### CSS-переменные `--bg`, `--text`…

Задают всю палитру одним местом. Чтобы поменять тему — правишь 8 значений в `:root`, остальные правила подтягиваются автоматически через `var(--bg)`.

- `--bg: #0a0a0a` — почти чёрный фон всего приложения
- `--bg-soft: #111111` — фон полей ввода и кнопок (чуть светлее)
- `--bg-card: #141414` — фон карточек при hover
- `--border: #1f1f1f` — тонкие разделители
- `--border-strong: #2a2a2a` — рамки активных элементов
- `--text: #fafafa` — основной светлый текст
- `--text-muted: #a3a3a3` — второстепенный текст
- `--text-dim: #525252` — подписи, timestamps

### Шрифты Geist

```css
@import url('https://fonts.googleapis.com/css2?family=Geist:wght@300;400...');
```

`Geist` и `Geist Mono` — свободные шрифты от Vercel. Подключаются с Google Fonts без регистрации.

### Keyframes-анимации

```css
@keyframes fadeUp {from {opacity: 0; transform: translateY(16px);} to {opacity: 1; transform: translateY(0);}}
@keyframes pulse {0%, 100% {opacity: 1; transform: scale(1);} 50% {opacity: 0.5; transform: scale(0.85);}}
@keyframes scroll {from {transform: translateX(0);} to {transform: translateX(-50%);}}
@keyframes blink {0%, 49% {opacity: 1;} 50%, 100% {opacity: 0;}}
...
```

- `fadeUp` — плавное появление снизу вверх. Используется для hero-заголовка, статистики, карточек фич.
- `pulse` — мигающий зелёный кружок-индикатор «система активна».
- `scroll` — бесконечная бегущая строка технологий (`marquee`).
- `blink` — курсор в конце заголовка и в терминале.
- `typing`, `termReveal`, `scrollDown`, `shimmer`, `float` — дополнительные эффекты.

### Scroll-pinned анимация терминала

```css
.terminal-stage {height: 280vh; view-timeline-name: --term-scroll;}
.terminal-sticky {position: sticky; top: 8vh;}

@supports (animation-timeline: view()) {
    .term-line.l1 {animation-range: cover 5% cover 12%;}
    .term-line.l2 {animation-range: cover 12% cover 19%;}
    ...
}
@supports not (animation-timeline: view()) {
    .term-line.l1 {animation-delay: 1.4s;}
    .term-line.l2 {animation-delay: 2.5s;}
    ...
}
```

**Идея:** терминал «прилипает» к верху экрана на высоту 2.8 экрана, и по мере прокрутки появляются строки кода. Современная CSS-фича `animation-timeline: view()` привязывает анимацию к позиции элемента в viewport.

**`@supports` fallback:** если браузер не поддерживает timeline-анимации (Safari, старый Firefox) — используем обычные `animation-delay`. Выглядит почти так же, только не зависит от скорости скролла.

### Переопределение дефолтных стилей Streamlit

```css
.stButton button[kind="primary"] {background: var(--text); color: var(--bg); ...}
.stTextArea textarea {background: var(--bg-soft) !important; ...}
.stTabs [aria-selected="true"]::after {content: ""; ...}
.stSlider div[role="slider"] {background: var(--text) !important; ...}
.streamlit-expanderHeader {background: var(--bg-soft) !important; ...}
```

Streamlit по умолчанию в светлой теме. Эти правила переопределяют его стандартные компоненты в тёмную палитру проекта. `!important` нужен потому, что у Streamlit inline-стили с высоким приоритетом.

**Как узнать нужный селектор:** открыть DevTools (F12) в браузере на странице приложения, ткнуть в элемент, скопировать селектор.

## Утилиты форматирования

### `красивое_имя_файла(имя)`

```python
def красивое_имя_файла(имя):
    без_расширения = имя[:-4] if имя.lower().endswith(".pdf") else имя
    чистое = без_расширения.replace("_", " ").replace("--", " — ")
    чистое = re.sub(r"\s+", " ", чистое).strip()
    if len(чистое) > 80:
        чистое = чистое[:77] + "…"
    return чистое
```

Приводит имя файла вида `s13321-020-00442-7_preprint--v2.pdf` к виду `s13321-020-00442-7 preprint — v2`.

**Шаги:**

1. Убрать расширение `.pdf`.
2. Подчёркивания → пробелы. Двойной дефис → тире (длинное).
3. Сжать множественные пробелы в один.
4. Обрезать до 80 символов с многоточием (иначе длинные имена ломают вёрстку).

### `построить_источники_html(фрагменты)`

```python
def построить_источники_html(фрагменты):
    группы = {}
    порядок = []
    for фр in фрагменты:
        имя = фр["document"]
        стр = фр["page"]
        if имя not in группы:
            группы[имя] = []
            порядок.append(имя)
        if стр not in группы[имя]:
            группы[имя].append(стр)

    строки = ""
    for i, док in enumerate(порядок, 1):
        страницы = ", ".join(str(p) for p in sorted(группы[док]))
        имя = красивое_имя_файла(док)
        строки += (
            f'<div class="source-row">'
            f'<span class="num">{i:02d}</span>'
            f'<span class="doc">{имя}</span>'
            f'<span class="pages">стр. {страницы}</span>'
            f'</div>'
        )
    return строки
```

**Проблема:** одна статья может дать 3 фрагмента с разных страниц. Показывать её 3 раза некрасиво. Нужно группировать.

**Алгоритм:**

1. Словарь `группы`: ключ — имя документа, значение — список уникальных страниц.
2. Список `порядок` помнит в каком порядке документы появились (словарь в Python 3.7+ тоже сохраняет порядок, но явное лучше).
3. Собираем HTML: один `<div class="source-row">` на документ, страницы через запятую.

Пример входа:

```python
[
    {"document": "a.pdf", "page": 3},
    {"document": "b.pdf", "page": 5},
    {"document": "a.pdf", "page": 7},
]
```

Выход:

```html
<div class="source-row"><span class="num">01</span><span class="doc">a</span><span class="pages">стр. 3, 7</span></div>
<div class="source-row"><span class="num">02</span><span class="doc">b</span><span class="pages">стр. 5</span></div>
```

## Функции-рендереры секций

### `применить_стили()`

```python
def применить_стили():
    st.markdown(CSS_БЛОК, unsafe_allow_html=True)
```

Одна строка. Вызывается один раз в начале `app.py`.

**`unsafe_allow_html=True`** — говорим Streamlit: «не экранируй HTML, выведи как есть». По умолчанию `st.markdown` экранирует `<tag>` в `&lt;tag&gt;` (чтобы защититься от XSS из пользовательского ввода). Нам нужен именно HTML.

**Почему строки склеиваются через пробел а не `+`:** в Python смежные строковые литералы автоматически конкатенируются. Работает только для литералов, не для переменных. Быстрее, чем `+`, и читается как один длинный HTML-блок.

### `показать_маркизу()`

```python
def показать_маркизу():

    for _ in range(2):                             # двойной прогон — ключевой момент
        for слово in _маркиза_слова:
```

**Почему двойной прогон:** CSS-анимация `scroll` двигает `.marquee-track` влево на `-50%`. Если элементов ровно на одну ширину — при сдвиге на `-50%` половина будет пустой. Если продублировать список — при сдвиге левая половина ушла, правая встала на её место, создавая **бесшовный цикл**.

### `показать_кейсы(кейсы)`

```python
def показать_кейсы(кейсы):
    html = '<div class="query-label-big">15 кейсов · применение Big Data в химии</div>'
    for индекс, (ключ, данные) in enumerate(кейсы.items(), 1):
        название = данные["название"]
        описание = _описания_кейсов.get(ключ, "")
        расш = _расширенные_кейсы.get(ключ, {})
        методы_li = "".join(f"<li>{м}</li>" for м in расш.get("методы", []))
        данные_li = "".join(f"<li>{д}</li>" for д in расш.get("данные", []))
        вопрос_примера = расш.get("вопрос", "")
        развёрнутый = (
            '<div class="case-expanded">'
            '<div class="case-exp-label">Методы и подходы</div>'
            f'<ul class="case-exp-list">{методы_li}</ul>'
            '<div class="case-exp-label">Типы данных</div>'
            f'<ul class="case-exp-list">{данные_li}</ul>'
            '<div class="case-exp-label">Пример вопроса к базе</div>'
            f'<div class="case-exp-quote">«{вопрос_примера}»</div>'
            '</div>'
        )
        html += (
            '<details class="case-details">'
            '<summary>'
            f'<div class="case-num">{индекс:02d}</div>'
            f'<div><div class="case-title">{название}</div><div class="case-desc">{описание}</div></div>'
            '<div class="case-toggle">+</div>'
            '</summary>'
            f'{развёрнутый}'
            '</details>'
        )
    st.markdown(html, unsafe_allow_html=True)
```

**Ключевой момент — HTML-тег `<details>`:** это нативный сворачиваемый блок в HTML5. Без JavaScript — клик по `<summary>` раскрывает/сворачивает содержимое.

**Почему не `st.expander`:** у `st.expander` ограниченная стилизация, плюс создаёт каждый элемент отдельным блоком Streamlit. Нативный `<details>` позволяет делать сложную сетку внутри summary (3 колонки: номер, заголовок, плюсик) и весь список рендерится одной HTML-строкой.

**CSS `details[open] .case-toggle {transform: rotate(45deg);}`** превращает `+` в `×` при раскрытии.

```python
        )
    st.markdown(html, unsafe_allow_html=True)

    стек_html = '<div class="query-label-big" style="margin-top: 4rem;">Технологический стек</div>'
    for ключ, значение, подсказка in _стек_технологий:
        стек_html += (
            '<div class="tech-row">'
            f'<div class="tech-key">{ключ}</div>'
            f'<div class="tech-val">{значение}<span class="hint">{подсказка}</span></div>'
            '</div>'
        )
    st.markdown(стек_html, unsafe_allow_html=True)
```

Два отдельных `st.markdown` вызова, но рендерятся один под другим. Первый — 8 строк пайплайна, второй — 7 строк стека.

## Что можно менять безопасно

| Что | Где | Эффект |
|---|---|---|
| Цвета темы | `:root { --bg: ...; }` | Перекрасить всё приложение |
| Слова в бегущей строке | `_маркиза_слова` | Обновить маркизу |
| 3 карточки на главной | `_фичи` | Изменить заявленные возможности |
| Текст терминала | `показать_терминал()` | Поменять live demo |
| Этапы пайплайна | `_этапы_пайплайна` | Обновить вкладку «Архитектура» |
| Стек технологий | `_стек_технологий` | То же |
| Расширенные кейсы | `_расширенные_кейсы` | Другие методы/данные/вопросы во вкладке «Кейсы» |

Всё остальное — вёрстка и анимации — можно не трогать если дизайн устраивает.

## Что запомнить на защиту

1. **Весь CSS внутри Python-строки `CSS_БЛОК`.** Внедряется в страницу один раз через `st.markdown(..., unsafe_allow_html=True)`.
2. **CSS-переменные в `:root`** — одна точка управления цветами всей темы.
3. **`unsafe_allow_html=True`** отключает экранирование HTML в `st.markdown`. Без него `<div>` превратится в текст `<div>`.
4. **`<details>`/`<summary>`** — нативный HTML5 сворачиваемый блок, без JavaScript. Использован для вкладки «Кейсы».
5. **Двойной прогон маркизы** нужен для бесшовного цикла при CSS-animation `translateX(-50%)`.
6. **Scroll-pinned терминал** использует свежую CSS-фичу `animation-timeline: view()` + fallback на `animation-delay` для старых браузеров.
