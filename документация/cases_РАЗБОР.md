# Разбор файла cases.py

## Что делает этот файл

Этот файл — справочник. Он хранит все 15 кейсов проекта и умеет определять, к какому кейсу относится тот или иной текст из документа.

---

## Построчный разбор

### Словарь `кейсы`

```python
кейсы = {
    "поиск_молекул": {
        "название": "Поиск лекарственных молекул",
        "ключевые_слова": [...]
    },
    ...
}
```

**Что это:** Обычный словарь Python. Ключ — короткое техническое название кейса на русском (без пробелов, с подчёркиванием). Значение — ещё один словарь с двумя полями.

**Поле `название`** — это красивое русское название, которое покажем пользователю в интерфейсе. Например: `"Поиск лекарственных молекул"`.

**Поле `ключевые_слова`** — список слов и фраз (на английском и русском), которые характерны для этого кейса. Нужны для автоматического определения, к какому кейсу принадлежит фрагмент текста из PDF.

**Почему слова на двух языках:** Большинство документов на английском, но есть и русские. Чтобы находить нужные фрагменты в обоих случаях, список содержит варианты на обоих языках.

---

### Функция `определить_кейс`

```python
def определить_кейс(текст):
    текст_нижний = текст.lower()
```

**Строка 1:** Объявляем функцию. Принимает на вход текст фрагмента (чанка) из PDF.

**Строка 2:** Переводим весь текст в нижний регистр. Это нужно чтобы слово `"Toxicity"` и `"toxicity"` считались одинаковыми. Иначе поиск будет пропускать слова в начале предложений.

```python
    лучший_кейс = "компетенции"
    лучший_счёт = 0
```

**Строка 3:** Задаём кейс по умолчанию. Если ни одно ключевое слово ни одного кейса не найдено — фрагмент относим к кейсу "компетенции" (самый общий).

**Строка 4:** Счётчик совпадений. Начинаем с нуля.

```python
    for ключ, данные in кейсы.items():
        счёт = sum(1 for слово in данные["ключевые_слова"] if слово.lower() in текст_нижний)
```

**Строка 5:** Перебираем все 15 кейсов.

**Строка 6:** Считаем, сколько ключевых слов данного кейса встречается в тексте. `sum(1 for ...)` — это компактный способ посчитать количество элементов, удовлетворяющих условию.

Например: если в тексте есть слова `"toxicity"` и `"LD50"`, то для кейса `"токсичность"` счёт будет 2.

```python
        if счёт > лучший_счёт:
            лучший_счёт = счёт
            лучший_кейс = ключ
    return лучший_кейс
```

**Строки 7–9:** Если текущий кейс набрал больше совпадений чем предыдущий лучший — обновляем победителя.

**Строка 10:** Возвращаем ключ кейса с максимальным числом совпадений.

**Что будет если убрать:** Фрагменты не будут тегированы кейсами. Фильтрация по кейсу в интерфейсе перестанет работать — Qdrant не сможет отфильтровать нужные документы.

### Функция `получить_название_кейса`

```python
def получить_название_кейса(ключ):
    if ключ in кейсы:
        return кейсы[ключ]["название"]
    return "Неизвестный кейс"
```

**Что делает:** Принимает технический ключ (`"токсичность"`) и возвращает красивое русское название (`"Прогноз токсичности вещества"`).

**Зачем:** В интерфейсе Streamlit мы показываем пользователю красивые названия, а в Qdrant хранятся короткие технические ключи. Эта функция служит переводчиком между ними.

**Строка `if ключ in кейсы`:** Защита от ошибки. Если ключ неизвестен — возвращаем заглушку вместо падения программы.

---

## Как это используется в других файлах

- `ingest.py` вызывает `определить_кейс(текст)` для каждого чанка из PDF
- `app.py` использует словарь `кейсы` чтобы показать список из 15 кейсов в боковой панели
- `app.py` вызывает `получить_название_кейса()` чтобы перевести ключ в красивое название
