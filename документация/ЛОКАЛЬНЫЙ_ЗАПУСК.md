# Локальный запуск

## Требования

- Python 3.10+ (рекомендуется 3.12)
- ~4 GB свободного места (модели + данные)
- ~4 GB RAM минимум (модели загружаются в память)
- Интернет для скачивания моделей при первом запуске
- Groq API ключ (бесплатный, для LLM-ответов)

---

## Установка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/newnout6-a11y/Big-data-in-.git "Big data in химия"
cd "Big data in химия"
```

### 2. Создать виртуальное окружение

```bash
python -m venv .venv

# Windows:
.venv\Scripts\activate

# Linux/macOS:
source .venv/bin/activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

Основные пакеты:
- `streamlit` — веб-интерфейс
- `sentence-transformers` — эмбеддинги (скачает ~440 MB модель e5-base + ~600 MB reranker)
- `qdrant-client` — клиент векторной БД (включает embedded mode)
- `protobuf>=3.20.3,<5` — для gRPC (qdrant-client зависимость)
- `pypdf`, `pymupdf` — извлечение текста из PDF
- `groq` — API-клиент Groq LLM
- `fastembed` — BM25 sparse-векторы
- `rapidocr-onnxruntime` — OCR страниц (CPU, Tier 1)
- `easyocr` — OCR изображений (~1 GB с моделями, опционально)
- `python-docx`, `genanki` — экспорт учебных материалов
- `httpx` — HTTP-клиент для харвестера

### 4. Настроить `.env`

```bash
cp .env.example .env
```

Минимальная конфигурация:
```env
GROQ_API_KEY=gsk_ваш_ключ
```

Получить: [console.groq.com](https://console.groq.com/) → API Keys → Create (бесплатно, 30 req/мин на бесплатном тарифе).

Опционально (для Qdrant Cloud вместо локальной базы):
```env
QDRANT_URL=https://your-cluster.region.aws.cloud.qdrant.io:6333
QDRANT_API_KEY=your_api_key
```

Опционально (для харвестера):
```env
HARVESTER_EMAIL=your@email.com
CORE_API_KEY=...
SEMANTIC_SCHOLAR_API_KEY=...
```

## Подготовка данных

### Вариант A: Импорт готовых данных из Qdrant Cloud

Если у вас уже есть заполненная коллекция в Qdrant Cloud:

```bash
# Скачать snapshot (JSONL с векторами и payload):
python scripts/download_snapshot.py --mode jsonl

# Импортировать в локальный Qdrant (все векторы):
python scripts/import_snapshot.py

# Или с ограничением (если RAM < 8 GB):
python scripts/import_snapshot.py --limit 40000

# Снести старую базу и залить заново:
python scripts/import_snapshot.py --recreate --limit 40000
```

Скрипт берёт готовые векторы из JSONL — **не пересчитывает** эмбеддинги (мгновенно, ~500 pt/s).
Идемпотентный: повторный запуск пропускает уже загруженные точки (по uuid5 от text_hash).
Лимит проверяется ДО загрузки батча — не будет превышения.

### Вариант B: Собрать данные с нуля

```bash
# 1. Положить документы (PDF/DOCX/TXT) в all_pdfs/
#    Или использовать харвестер:
python -m harvester.run --budget 100 --email your@email.com

# 2. Извлечь чанки (авторазметка, дедуп, фильтр качества):
python pipeline/ingest_v2.py

# 3. Векторизовать (dense + sparse → Qdrant):
python pipeline/embed_resume_v2.py
```

Время (ориентир на CPU, Intel i5-12th gen):
- `harvester.run --budget 100`: ~5-15 мин (зависит от API и сети)
- `ingest_v2.py`: ~1-2 сек/файл (зависит от размера PDF)
- `embed_resume_v2.py`: ~10-30 мин на 50 000 чанков (батчи по 64)

## Запуск приложения

### Только локально

```bash
streamlit run ui/app.py --server.port 8501
```

Открыть http://localhost:8501

**Первый запуск будет медленнее** — скачиваются модели:
1. `intfloat/multilingual-e5-base` (~440 MB) — для поиска
2. `BAAI/bge-reranker-v2-m3` (~600 MB) — для reranker'а
3. `Qdrant/bm25` (~50 MB) — для BM25

После первого запуска модели кэшируются, старт занимает ~10-15 сек.

### С публичной ссылкой (для демонстрации)

```bash
python запуск.py
```

Что происходит:
1. Завершает старые процессы на порту 8501
2. Запускает Streamlit в фоне
3. Создаёт SSH-туннель через `localhost.run` (бесплатно, работает из РФ без VPN)
4. Генерирует QR-код (`qr.png`) и открывает его
5. Выводит публичную ссылку `https://xxx.lhr.life`

```
Локально:         http://localhost:8501
Публичная ссылка: https://xxx.lhr.life
QR-код:           qr.png
```

Остановка: `Ctrl+C`.

## Структура данных на диске

```
.
├── all_pdfs/           # Исходные документы (PDF/DOCX/TXT) — не в git
├── harvested_meta/     # Метаданные из харвестера (JSON) — не в git
├── extracted_images/   # Извлечённые изображения (по SHA-256 PDF)
├── rejected_pdfs/      # Отбракованные фильтром качества
├── chunks_v2.jsonl     # Чанки с метаданными (~670 MB для полного корпуса)
├── knowledge_hybrid_export.jsonl  # Готовые векторы из Qdrant Cloud (~6 GB)
├── qdrant_db/          # Локальная база Qdrant (embedded mode)
├── user_documents/     # Загруженные пользовательские тетради
├── visual_index/       # Кэш визуальной обработки (OCR)
│   ├── pages/          # Кэш по page_hash (SHA-256)
│   └── budget.json     # Счётчик страниц Groq Vision
├── prototype_cache.npz # Кэш эмбеддингов прототипов таксономии
├── harvester/
│   ├── state.json      # Курсоры и дедуп-списки харвестера
│   └── logs/           # Логи запусков
└── exports/            # Экспортированные карточки, конспекты
```

## Модели (скачиваются автоматически при первом запуске)

| Модель | Размер | Назначение | Скорость (CPU) |
|--------|--------|-----------|---------------|
| `intfloat/multilingual-e5-base` | ~440 MB | Dense-эмбеддинги 768d | ~200 texts/s |
| `BAAI/bge-reranker-v2-m3` | ~600 MB | Cross-encoder reranker | ~60 pairs/s |
| `Qdrant/bm25` | ~50 MB | BM25 токенизация (не нейросеть) | мгновенно |

Кэшируются в:
- Linux/macOS: `~/.cache/huggingface/hub/`
- Windows: `%USERPROFILE%\.cache\huggingface\hub\`

## Устранение проблем

### Streamlit не запускается

```bash
# Проверить что порт свободен:
# Windows:
netstat -an | findstr 8501
# Linux:
lsof -i :8501

# Проверить логи:
cat _streamlit.log
```

### Qdrant ошибки / коллекция пустая

```bash
# Проверить коллекции:
python -c "
from qdrant_client import QdrantClient
c = QdrantClient(path='qdrant_db')
for col in c.get_collections().collections:
    info = c.get_collection(col.name)
    print(f'{col.name}: {info.points_count} точек')
"
```

### Нет GPU / медленно

Всё работает на CPU. GPU ускоряет encode в ~5x, но не обязателен.
- Ингест 1000 PDF: ~20 мин (CPU)
- Embed 50k чанков: ~20-30 мин (CPU)
- Поиск: ~0.5-1 сек (включая reranker)

Повторный запуск `embed_resume_v2.py` быстрый — идемпотентный (пропускает уже загруженные по text_hash).

### Rate Limit Groq

Бесплатный тир: 30 requests/min, 14,400/day.

Если упираетесь:
- Система автоматически использует fallback модель `llama-3.1-8b-instant` при 429
- Добавить второй ключ: `GROQ_API_KEY_2=gsk_...` — система переключится при rate-limit

### ImportError: protobuf

```bash
pip install "protobuf>=3.20.3,<5"
```

Нужен для qdrant-client gRPC. Уже в requirements.txt.

### PyMuPDF не установился (Windows)

```bash
pip install pymupdf --no-build-isolation
```

Или использовать pre-built wheel:
```bash
pip install pymupdf --only-binary=:all:
```
