# Локальный запуск

## Требования

- Python 3.10+ (рекомендуется 3.12)
- ~4 GB свободного места (модели + данные)
- Интернет для скачивания моделей при первом запуске

---

## Установка

### 1. Клонировать репозиторий

```bash
git clone <url> "Big data in химия"
cd "Big data in химия"
```

### 2. Создать виртуальное окружение

```bash
python -m venv .venv

# Windows:
.venv\Scripts\activate

# Linux/macOS:
source .venv/bin/activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

Основные пакеты:
- `streamlit` — веб-интерфейс
- `sentence-transformers` — эмбеддинги (скачает ~500 MB модели)
- `qdrant-client` — клиент векторной БД
- `pypdf`, `pymupdf` — извлечение текста из PDF
- `groq` — API-клиент Groq
- `fastembed` — BM25 sparse-векторы
- `rapidocr-onnxruntime` — OCR (CPU)
- `easyocr` — OCR изображений (~1 GB с моделями)
- `python-docx`, `genanki` — экспорт учебных материалов

### 4. Настроить `.env`

```bash
cp .env.example .env
```

Минимальная конфигурация:
```env
GROQ_API_KEY=gsk_ваш_ключ
```

Получить: [console.groq.com](https://console.groq.com/) → API Keys → Create.

Опционально (для Qdrant Cloud):
```env
QDRANT_URL=https://your-cluster.qdrant.io:6333
QDRANT_API_KEY=your_api_key
```

## Подготовка данных

### Вариант A: Импорт готовых данных из Qdrant Cloud

Если у вас уже есть заполненная коллекция в Qdrant Cloud:

```bash
# Скачать snapshot (JSONL с векторами и payload):
python scripts/download_snapshot.py --mode jsonl

# Импортировать в локальный Qdrant:
python scripts/import_snapshot.py
```

### Вариант B: Собрать данные с нуля

```bash
# 1. Положить документы (PDF/DOCX/TXT) в all_pdfs/
#    Можно использовать харвестер:
python -m harvester.run --budget 100

# 2. Извлечь чанки:
python pipeline/ingest_v2.py

# 3. Векторизовать:
python pipeline/embed_resume_v2.py
```

Время (ориентир на CPU):
- `ingest_v2.py`: ~1-2 сек/файл (зависит от размера PDF)
- `embed_resume_v2.py`: ~10-30 мин на 50 000 чанков

## Запуск приложения

### Только локально

```bash
streamlit run ui/app.py --server.port 8501
```

Открыть http://localhost:8501

### С публичной ссылкой (для демонстрации)

```bash
python запуск.py
```

Что происходит:
1. Завершает старые процессы на порту 8501
2. Запускает Streamlit в фоне
3. Создаёт SSH-туннель через `localhost.run`
4. Генерирует QR-код (`qr.png`) и открывает его
5. Выводит публичную ссылку `https://xxx.lhr.life`

```
Локально:         http://localhost:8501
Публичная ссылка: https://xxx.lhr.life
QR-код:           qr.png
```

Ссылка работает из РФ без VPN. Остановка: `Ctrl+C`.

## Структура данных на диске

```
.
├── all_pdfs/           # Исходные документы (PDF/DOCX/TXT)
├── harvested_meta/     # Метаданные из харвестера (JSON)
├── extracted_images/   # Извлечённые изображения (по хэшу PDF)
├── chunks_v2.jsonl     # Чанки с метаданными (~670 MB для полного корпуса)
├── qdrant_storage/     # Локальная база Qdrant
├── prototype_cache.npz # Кэш прототипов классификатора
├── user_documents/     # Загруженные пользовательские документы
└── visual_index/       # Кэш визуальной обработки (OCR)
```

## Модели (скачиваются автоматически)

| Модель | Размер | Назначение |
|--------|--------|-----------|
| `intfloat/multilingual-e5-base` | ~500 MB | Dense-эмбеддинги |
| `BAAI/bge-reranker-v2-m3` | ~600 MB | Cross-encoder reranker |
| `Qdrant/bm25` | ~50 MB | BM25 токенизация |

Кэшируются в `~/.cache/huggingface/` (Linux) или `%USERPROFILE%\.cache\huggingface\` (Windows).

## Устранение проблем

### Streamlit не запускается

```bash
# Проверить что порт свободен:
netstat -an | findstr 8501

# Проверить логи:
cat _streamlit.log
```

### Qdrant ошибки

```bash
# Проверить коллекции:
python -c "from qdrant_client import QdrantClient; c=QdrantClient(path='qdrant_storage'); print([x.name for x in c.get_collections().collections])"
```

### Нет GPU / медленно

Всё работает на CPU. Эмбеддинг 50k чанков занимает ~20-30 мин. Повторный запуск `embed_resume_v2.py` быстрый (идемпотентный — пропускает уже загруженные).

### Rate Limit Groq

- Добавить второй ключ: `GROQ_API_KEY_2=gsk_...`
- Система автоматически переключится при 429
