# Разбор файла fallback_answers.py

## Что делает этот файл

Хранит 5 заранее подготовленных пар «вопрос–ответ» с источниками. Используется когда Groq API недоступен (нет интернета, исчерпан лимит, технические проблемы на защите).

---

## Зачем это нужно

На защите всегда могут случиться:
- Нет интернета в аудитории
- Groq API не отвечает (перегрузка серверов)
- Закончился бесплатный лимит запросов
- Qdrant не загрузилась (не прогнали `embed_and_load.py`)

В этих случаях включается **демо-режим** в интерфейсе. Кнопка-переключатель «Демо-режим» в левой колонке. При включении — все ответы берутся из этого файла.

---

## Структура данных

```python
заготовленные_ответы = [
    {
        "вопрос": "...",
        "ответ": "...",
        "кейс": "...",
        "источники": ["...", "..."]
    },
    ...
]
```

Это список словарей. Каждый словарь = одна заготовка.

**Поля:**

- **`вопрос`** — текст демо-вопроса. Используется для подбора нужного ответа: если слова из вопроса пользователя совпадают со словами здесь — показываем этот ответ.
- **`ответ`** — готовый ответ на русском, написанный вручную. Содержит формулы, объяснения, практическую пользу.
- **`кейс`** — название кейса (для справки).
- **`источники`** — список источников в формате `имя_файла.pdf, стр. N`. Реальные файлы из нашей базы.

---

## Как используется в app.py

```python
def показать_демо_ответ(вопрос):
    вопрос_нижний = вопрос.lower()
    for запись in заготовленные_ответы:
        if any(слово in вопрос_нижний for слово in запись["вопрос"].lower().split()):
            return запись
    return заготовленные_ответы[0]
```

Функция в `app.py` перебирает заготовки и ищет совпадение хотя бы одного слова между вопросом пользователя и заготовленным вопросом. Если ничего не нашлось — возвращает первый ответ по умолчанию.

## 5 заготовленных тем

1. **Формула выхода реакции** — кейс «Прогноз выхода реакции»
2. **Предсказание токсичности** — кейс «Прогноз токсичности вещества»
3. **Что такое эмбеддинги** — кейс «Компетенции направления»
4. **GNN в химии** — кейс «Поиск лекарственных молекул»
5. **Байесовская оптимизация** — кейс «Оптимизация условий реакции»

## Как расширить

Чтобы добавить новый заготовленный ответ — добавь новый словарь в список:

```python
    {
        "вопрос": "Как работает QSAR?",
        "ответ": "QSAR (Quantitative Structure–Activity Relationship)...",
        "кейс": "Прогноз токсичности вещества",
        "источники": ["s13321-021-00518-y.pdf, стр. 2"]
    }
```
