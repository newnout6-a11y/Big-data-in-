# Визуальная обработка

## Обзор

Модуль `core/визуальная_обработка.py` отвечает за OCR и обработку страниц PDF для пользовательских тетрадей. Используется когда PyMuPDF не может извлечь текст (сканы, рукописные заметки, фотографии конспектов).

---

## Три уровня обработки (Tiers)

| Tier | Метод | Стоимость | Скорость | Качество |
|------|-------|-----------|----------|----------|
| 0 | PyMuPDF text extraction | бесплатно | мгновенно | высокое (для текстовых PDF) |
| 1 | RapidOCR по рендеру | бесплатно | ~1-3 сек/стр | среднее (печатный текст) |
| 2 | Groq Vision caption | ~$0.0004/стр | ~2-5 сек/стр | высокое (рукопись, схемы) |

### Логика выбора tier:

```
Страница PDF
  │
  ├── PyMuPDF text → достаточно слов? → Tier 0 (готово)
  │
  ├── Нет → RapidOCR → достаточно слов? → Tier 1 (готово)
  │
  └── Нет → Groq Vision (если доступен и бюджет позволяет) → Tier 2
```

Порог «достаточно слов»: `MIN_WORDS_GOOD = 20`.

---

## Кэширование

Каждая обработанная страница кэшируется по `page_hash` (SHA-256 от байтов страницы):

```
visual_index/<page_hash>.json
```

Повторная обработка того же PDF мгновенна — результаты берутся из кэша.

---

## Бюджет Groq Vision (Tier 2)

Файл `visual_index/_budget.json`:

```json
{
  "total_pages": 150,
  "max_pages": 500,
  "last_reset": "2024-05-20T12:00:00Z"
}
```

- `MAX_GROQ_PAGES_DEFAULT = 500` — лимит страниц на Groq Vision
- Каждый вызов увеличивает `total_pages`
- При превышении бюджета Tier 2 пропускается

## Модуль извлечения картинок (core/извлечение_картинок.py)

Извлекает изображения из PDF-страниц для двух пайплайнов:
- `pipeline/ingest_v2.py` — массовый ингест корпуса
- `core/notebooks.py` — загрузка пользовательских документов

### Фильтрация

Декоративные изображения отбрасываются:
- Размер < 80px по любой стороне
- Соотношение сторон > 10:1 (полоски, линии)
- Повторяющиеся фоновые изображения (шаблоны журналов)
- Логотипы издательств (по хэшу xref)

### Привязка подписей

```python
извлечь_подписи_со_страницы(page) → список подписей с bbox
привязать_подписи(картинки, подписи) → картинки с caption
```

Алгоритм: для каждой картинки ищется ближайшая подпись ниже/выше по bbox proximity.

### OCR изображений

```python
ocr_картинки(images) → тексты
```

Использует EasyOCR для распознавания текста на схемах и диаграммах.

### Vision caption

```python
vision_caption_картинки(images) → описания
```

Опциональный Groq Vision для генерации текстового описания сложных схем.

## Dataclass

```python
@dataclass
class СтраницаВизуал:
    page_num: int
    text: str           # извлечённый текст
    tier: int           # 0, 1 или 2
    cached: bool        # из кэша или обработан заново
    ocr_text: str       # результат OCR (tier 1)
    vision_text: str    # результат Groq Vision (tier 2)
```

---

## Использование

```python
from визуальная_обработка import обработать_pdf, budget_summary

# Обработать PDF:
страницы = обработать_pdf("path/to/file.pdf", groq_api_key="gsk_...")
# → [СтраницаВизуал(...), ...]

# Проверить бюджет:
info = budget_summary()
# → {"total_pages": 42, "max_pages": 500, "remaining": 458}
```

## Зависимости

| Пакет | Назначение |
|-------|-----------|
| `pymupdf` (fitz) | Рендер страниц в PNG, text extraction |
| `rapidocr-onnxruntime` | OCR Tier 1 (CPU, без системных зависимостей) |
| `easyocr` | OCR текста на изображениях |
| `pillow` | Обработка изображений |
| `groq` | API для Vision caption (Tier 2) |
