# Учебные инструменты

## Обзор

Вкладка «Учёба» в UI предоставляет набор инструментов для генерации учебных материалов на основе загруженных документов. Вся логика — в `core/study_tools.py`, вызывается из `ui/app.py`.

---

## Функции

### 1. Конспекты

Генерация тезисного пересказа лекции или главы через LLM.

**Режимы:**
- **Вся лекция** — конспект всего документа целиком
- **Глава / тема** — конспект по выбранным страницам или теме

**Вход:** фрагменты из тетради (через `notebook_fragments()`) → текстовый контекст.
**Выход:** Markdown с формулами, определениями, ключевыми тезисами.

**Экспорт:**
- Markdown (`.md`)
- DOCX с формулами (Office Math XML)

### 2. Флеш-карточки

Генерация карточек «вопрос — ответ» из содержимого документа.

**Процесс:**
1. LLM получает фрагменты и генерирует JSON-массив карточек
2. `parse_json_loose()` извлекает JSON даже при неидеальном ответе LLM
3. Карточки обогащаются источниками (номер страницы, документ)

**Форматы экспорта:**
| Формат | Функция | Описание |
|--------|---------|----------|
| Anki APKG | `build_apkg()` | Готовый пакет для Anki (через `genanki`) |
| TSV | `cards_to_tsv()` | Tab-separated, импорт в Anki/Quizlet |
| CSV | `cards_to_csv()` | Comma-separated |
| DOCX | `cards_docx_export()` | Для печати / офлайн-повторения |

### 3. Квизы

Генерация вопросов с вариантами ответов (multiple choice).

**Процесс:**
1. LLM генерирует вопросы с 4 вариантами + правильный ответ
2. Парсинг JSON с fallback на regex
3. UI показывает интерактивный квиз с проверкой

### 4. Граф связей

Визуализация связей между понятиями в документе.

**Процесс:**
1. LLM извлекает ключевые понятия и связи между ними
2. `graphviz_dot()` строит DOT-описание графа
3. Рендеринг в SVG через `streamlit.components`

**Функции:**
- `_stable_int()` — стабильный хэш для ID узлов
- `_dot_id()` — безопасный идентификатор для Graphviz
- `_clean_cell()` — очистка текста ячейки

## Экспорт ответов из RAG

Помимо учебных инструментов, основной ответ RAG тоже экспортируется:

| Функция | Формат | Что включает |
|---------|--------|-------------|
| `markdown_export()` | `.md` | Ответ + источники + изображения (data-uri) |
| `docx_export()` | `.docx` | Ответ с формулами (Office Math) + изображения |

Особенности DOCX-экспорта:
- LaTeX формулы → Office Math XML (`_omath()`, `_math_fragments()`)
- Маркеры `[img:N.M]` → встроенные изображения
- Стили: заголовки, выделение, выравнивание

## Вкладка UI: структура

```
Вкладка «Учёба»
├── Выбор тетради (selectbox)
├── Выбор документа (selectbox)
└── Под-вкладки:
    ├── Конспект
    │   ├── Кнопка «Тезисно всю лекцию»
    │   └── Кнопка «Конспект главы / темы»
    ├── Карточки
    │   └── Кнопка «Сгенерировать учебные карточки»
    ├── Квиз
    │   └── Кнопка «Создать квиз»
    └── Граф
        └── Кнопка «Построить граф связей»
```
